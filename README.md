# Smart-Parking-Management-System-ANPR

## Overview

This project presents an IoT-enabled Smart Parking Management System that automates vehicle identification, parking slot monitoring, gate control, and parking management using Automatic Number Plate Recognition (ANPR).

The system integrates ESP32-CAM, Python, OpenCV, OCR, IR sensors, servo motors, and database connectivity to provide a real-time parking automation solution.

---

## Features

* Automatic Number Plate Recognition
* Vehicle Entry and Exit Monitoring
* Real-Time Parking Slot Detection
* Automated Gate Control
* Parking Duration Tracking
* Automated Billing System
* Database Logging and Storage
* LCD-Based User Information Display

## System Workflow

1. Vehicle arrives at parking entrance.
2. IR sensor detects vehicle presence.
3. ESP32-CAM captures vehicle image.
4. OCR extracts license plate information.
5. Vehicle details are stored in the database.
6. Parking availability is verified.
7. Gate opens automatically using servo motor.
8. Parking duration is tracked.
9. Vehicle exits through automated gate control.
10. Parking records are updated and billing is generated.
